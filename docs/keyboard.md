# Keyboard shortcuts

Rigel uses Cmd on macOS and Ctrl on Windows and Linux. These shortcuts are in the current source. Check the installed package version before relying on them.

| Action | Shortcut |
| --- | --- |
| Search content | Cmd/Ctrl + K |
| Save | Cmd/Ctrl + S |
| Switch Browse and Edit | Cmd/Ctrl + Shift + E |
| Toggle navigation sidebar | Cmd/Ctrl + B |
| Toggle properties panel | Cmd/Ctrl + Shift + Y |
| Open keyboard shortcuts | Cmd/Ctrl + / |
| Close a dialog, menu or search | Escape |

Search and Save also work when focus is inside the prepared page preview. Browse/Edit and the properties panel apply to documents and articles that use the visual editor.

Save runs the same checks as the Save button. It writes nothing for an unchanged draft, while a save, publish, reindex or open dialog is busy, or when the editor is not connected. Layout shortcuts are ignored while a text field or rich text block has focus, so Cmd/Ctrl + B keeps its usual bold behavior in the article editor.

Shortcuts are fixed. Rigel does not offer per-user key remapping.
